## Safety work in this phase

- New bans, all canary-checked: `ServerManager(string)` (read-write) and `OpenRemote`, `SetMetadata`;
  `EventLogConfiguration`; `X509Store` add/remove; private-key access and password exports.
- Source rule: certificate stores open only `ReadOnly`/`OpenExistingOnly`; chains are built offline (no certificate
  downloads, no revocation lookups) — RSM makes no internet calls.
- `Microsoft.Web.Administration` pulled in the netstandard1.x ServiceController 4.1.0, against which a ServiceController
  ban did not resolve (the canary test caught it); ServiceController is pinned to 8.0.1 so every ban matches the API.
- Server files are read only through `ReadOnlyFile` (new: listing with size/time, offset reads); IIS configuration is
  parsed from files, so remote nodes never need a writable management API.
- `*.log` was git-ignored: the hand-built IIS log fixtures were missing from CI (run 17/18 red) — now committed with an
  ignore exception and `-text` so their CRLF bytes are exact.

## Acceptance evidence

- **W3C percentiles** match the hand-verified sample (`IisLogParserTests`): `/api/voucher` 10 requests → p50 110 ms,
  p95 = p99 = max 5000 ms; `/login` 7 requests across a `#Fields` change → p50 60, p95 = p99 = 70; 12×503 burst at
  06:05, 502.5 and 500.30 decoded, win32 64 counted as a client disconnect, malformed line counted not parsed.
- **web.config never shows a secret** (`IisConfigParserTests`, `IisCollectorTests`): the fixture carries 14 secret
  values (connection-string passwords and user, Redis password, JWT key, tokens, client secret, mail password, URL
  credentials, legacy pwd, arguments token, environment connection string and JWT, machine keys); none appears in the
  parsed model or the collector payload.
- **Event KB covers every §9.8 event** (`EventsAndServicesTests.Knowledge_base_covers_every_event_named_in_the_spec`,
  37 provider/id cases incl. named SQL instances, ASP.NET versions and ANCM V2), every entry is bilingual and links
  only to rules that exist.
- **ARR farm + rewrite checks** verified on fixtures: farm with a disabled server (ARR-002), empty farm (ARR-001),
  rewrite to `/Rahkaran72` while only `/Rahkaran73` is deployed → `segment_deployed = false` (ARR-004), unknown farm
  name (ARR-005), measured distribution 900:100 vs 1:1 weights → 80 % deviation (ARR-003).
- **Live requests for a slow endpoint** (CI job *IIS live requests…*, Windows runner, IIS + Request Monitor +
  ASP.NET, `/slow.aspx` sleeping 40 s): see the run listed in the report; the same job checks capabilities, IIS
  configuration facts, identical `win.iis.*` keys over PDH and CIM, services and event logs, and compares
  `applicationHost.config`'s hash and the pool state before/after (read-only proof).
