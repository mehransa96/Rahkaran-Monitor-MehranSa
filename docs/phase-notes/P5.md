## Safety work in this phase

- RSM still runs no SQL of its own. History, baselines and investigations are files written only through
  `IDataFolder`, which gained `AppendAllBytesAsync` (resolved inside the root like every write) and
  `ListDirectories`.
- WebView2 is confined to one file, kept offline, and its PDF goes through `IDataFolder`. The arch test checks the
  guards are present and forbids `NavigateToString`, script execution, host objects, `PrintToPdfAsync(path)` and
  dev tools.
- Bundle import reads user-chosen files read-only (`ReadOnlyFile`), caps sizes, refuses foreign formats with a
  reason, and never executes anything from a bundle. Merging only re-evaluates the rules.
- The slowness capture only raises the cadence of the existing read-only collectors for its duration and always
  restores it. Every next step is text, and every cause and detector carries a `general` source ("confirm with
  ستاد فنی").
- `--ui-snapshots` connects to nothing: no site is selected and no live view is started.
